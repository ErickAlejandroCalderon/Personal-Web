---

## Características Principales

*  **Soporte Multilingüe (i18n):** Alternancia en tiempo real entre **Español** e **Inglés** mediante `LanguageContext`.
*  **Modos Claro y Oscuro:** Soporte de temas dinámicos con persistencia y variables CSS fluidas (`ThemeContext`).
*  **Hero Interactivo & Terminal Animada:** Efecto de escritura progresiva y animación de terminal inspirada en herramientas modernas de desarrollo.
*  **Animaciones Cuidadas:** Transiciones suaves implementadas con [Anime.js](https://animejs.com/) y observadores de intersección (`IntersectionObserver`) para revelado en scroll.
*  **Diseño Moderno (Glassmorphism):** Desarrollado con CSS puro (Vanilla, sin frameworks pesados), color de acento característico `#FF8700` (Naranja vibrante).
* **Descarga de CV:** Acceso directo para descargar el currículum actualizado en PDF.
* **Secciones Claras y Profesionales:**
  * **Hero:** Introducción de impacto con código dinámico.
  * **About:** Perfil profesional y filosofía de trabajo.
  * **Skills:** Stack tecnológico (Frontend, Backend, DevOps, Bases de Datos).
  * **Projects:** Casos de estudio y proyectos relevantes (Terrabus, Nextcloud, etc.).
  * **Education:** Trayectoria académica y certificaciones.
  * **Contact:** Vías directas de contacto y enlaces a redes profesionales.
